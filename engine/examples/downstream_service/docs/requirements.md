# 报价服务需求

## POST /api/v1/quotes

- 请求字段 `sku` 长度 3–40，`quantity` 为 1–99 的整数。
- 报价总额等于下游返回的单价乘以数量，响应包含 `sku`、`quantity`、`total_cents`。
- 当价格服务返回 404 时，报价接口返回 404，表示商品不存在。
- 请求字段不合法时返回 422。

## 下游价格服务

### GET /v1/pricing

- 价格服务按 `sku` 返回 `unit_price_cents`。
- 正常分支返回 200；商品不存在返回 404。

## 健康检查

- `GET /health` 返回 200，仅用于就绪探测，不参与业务验收。
